# 供应商询盘邮件

## 什么时候用
用户要向中国的供应商、工厂或贸易商询问价格、起订量、样品或交期时。

## 开始写之前，先确认这些信息
缺少的信息先问用户，一次最多问三个问题，不要凭空编造：

1. 产品是什么（名称、材质、尺寸、用途），有没有图片或参考链接。
2. 大概的采购数量，是试单还是正式下单。
3. 目的地国家或城市（影响运费和贸易术语）。
4. 是否需要定制：自有品牌（OEM）、包装、Logo、颜色。
5. 用户希望邮件用中文还是英文。

## 邮件结构
1. **称呼和自我介绍**：一两句话，说明公司或网店、做什么业务。
2. **需求说明**：产品名称、规格、数量，并列出要对方回答的问题。
3. **要对方提供的信息**（用编号列表，方便对方逐条回复）：
   - 单价，最好按数量档位报价（例如 100 / 500 / 1000 件）。
   - 起订量（MOQ）。
   - 贸易术语和报价口径（EXW、FOB、CIF 等），是否含税。
   - 生产交期，以及样品的价格和制作时间。
   - 付款方式和定金比例。
   - 材质、工艺、认证（如 CE、RoHS、ISO）。
   - 是否支持定制和 OEM，以及相关费用。
4. **结尾**：说明希望什么时候收到回复，写清联系方式。

## 写作要求
- 语气礼貌、简洁、具体。一封邮件只谈一件事。
- 问题要具体、可回答，避免"请报价"这种空泛的说法。
- 不要在第一封邮件里透露预算上限、底价或其他供应商的报价。
- 不要承诺一定下单；可以说"如果价格和质量合适，我们计划试单"。
- 不要编造公司信息、订单量或认证。用户没说的，留成 `[待补充]`。
- 中文邮件用"您"，英文邮件用 Dear / Best regards 这类通用格式。

## 输出格式
1. 邮件主题（一行，包含产品名称和"询价"或 Inquiry）。
2. 邮件正文。
3. 最后用一两句话提示用户：哪些地方需要自己补充，以及回复到来后该重点核对什么（单价口径、起订量、交期）。

## 中文示例（结构参考，不要照抄）
主题：关于【产品名称】的询价

您好，

我们是 [公司或店铺名称]，主要通过独立站销售 [产品类别]。我们对贵司的 [产品名称] 很感兴趣，想了解以下信息：

1. 参考数量 [数量] 件的单价，以及 500 / 1000 件的阶梯价。
2. 起订量（MOQ）。
3. 报价是 EXW 还是 FOB？是否含税？
4. 样品价格和制作周期。
5. 批量订单的生产周期。
6. 是否支持自有品牌（Logo、包装）定制？

期待您的回复，谢谢！

此致
[姓名]
[联系方式]
